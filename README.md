# CRITICAL ANALYSIS REPORT
This repo contains a report presenting a critical evaluation of a 
dashboard developed by me using Dublin's 2021 
Residential Property Price Register (PPR) 
dataset. The Residential Property Price 
Register is officially published by the 
Property Services Regulatory Authority 
(PSRA) under Section 86 of the Property 
Services (Regulation) Act 2011. The dataset 
records all residential property transactions in 
Ireland since 1 January 2010, based on 
declarations submitted to the Revenue 
Commissioners for stamp duty purposes. It 
provides detailed transactional information 
including date of sale, sale price, property 
address, 
county, and classification of 
dwelling type (new or second-hand).
